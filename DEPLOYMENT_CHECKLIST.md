# Submission checklist

- [ ] FastAPI service created.
- [ ] `GET /health` works.
- [ ] `POST /query` works.
- [ ] Swagger UI works at `/docs`.
- [ ] Retrieval returns source filename + snippet.
- [ ] Weak retrieval returns the explicit "I don't have enough information to answer that." response.
- [ ] Structured JSON logs are visible in hosting logs.
- [ ] `GOOGLE_API_KEY` is configured as a secret environment variable.
- [ ] Public Render URL copied into the submission.
- [ ] The original exposed Google API key was revoked/rotated.
- [ ] Optional: add Langfuse Hobby if the instructor specifically asks for LLM tracing.
